Privacy Policy for PetaPikir

Effective Date: November 23, 2026 · Package: com.aistudio.petapikir.krmxvp

PetaPikir ("the App") is a 100% offline mind-mapping application for Android. This Privacy Policy explains how the App stores and protects your data exclusively on your device.

1. Zero Data Collection & Zero Network Permissions

  • PetaPikir does not request INTERNET or network permissions.
  • PetaPikir does not require sign-in, accounts, analytics, tracking, or advertisements.
  • All mind map titles, nodes, links, and colors remain strictly on your local Android device.

2. On-Device Storage & Automatic Local Backup

  • Your mind maps are saved in an on-device Room database for fast offline editing.
  • Every create, edit, and delete is automatically saved as one JSON file at /storage/emulated/0/autosync/petapikir_backup_json/petapikir.json. The path is fixed and cannot be changed in the App.
  • PetaPikir never requests broad all-files storage permissions (such as MANAGE_EXTERNAL_STORAGE).

3. Data Retention & Deletion

  • You have full control over the backup file petapikir.json and can move, copy, or delete it using any file manager at any time. Deleting a map writes a deletion marker to the file, and that marker is kept.
  • Uninstalling the App removes its internal database while preserving the backup file already saved in the autosync folder.
