PetaPikir

Aplikasi peta pikiran Radiant 360° yang bekerja 100% luring di Android dengan pencadangan otomatis langsung ke penyimpanan ponsel.

Arti Ikon & Navigasi

Cadangan Perangkat

Menampilkan status cadangan terakhir dan lokasi berkas cadangan di penyimpanan ponsel.

Mode Radiant

Menampilkan cabang memancar 360° dari pusat. Ketuk lagi saat aktif untuk masuk layar penuh lanskap.

Mode List

Mengubah peta pikiran menjadi daftar terstruktur yang nyaman dibaca dan disunting cepat.

Paskan Layar

Memusatkan ulang kanvas agar seluruh cabang peta pikiran pas terlihat di layar.

Cari Topik

Mencari judul cabang atau tautan web di dalam peta lalu langsung menyorot hasilnya.

Tautan Web

Ikon di sisi kanan cabang menandakan ada tautan web. Ketuk untuk membukanya di peramban.

Urungkan & Ulangi

Membatalkan atau mengembalikan perubahan terakhir pada struktur dan isi cabang.

Hapus Cabang (2 Mode)

Pilih hapus cabang beserta seluruh anaknya, atau hapus topik ini saja sambil menaikkan anak cabang.

Cara Menggunakan PetaPikir

  • Tambah & Sunting Cepat: Ketuk sebuah cabang untuk menampilkan bilah aksi, atau ketuk dua kali (double-tap) untuk langsung menyunting judul dan tautan web.
  • Layar Penuh Otomatis: Ketuk ikon Radiant saat sedang aktif untuk masuk mode layar penuh lanskap dengan kanvas otomatis mengepas layar.
  • Geser Urutan Cabang: Gunakan tombol geser kiri/kanan pada bilah aksi untuk mengatur urutan cabang tanpa perlu mengetik ulang.

Cadangan Perangkat Otomatis

Setiap perubahan peta pikiran langsung disimpan ke satu berkas petapikir.json di penyimpanan ponsel:

/storage/emulated/0/autosync/petapikir_backup_json/petapikir.json
  • Lokasi Tetap: Jalur berkas tetap dan tidak bisa dipilih ulang dari aplikasi.
  • Gabung Otomatis: Saat aplikasi dibuka, data dari berkas dan data di perangkat digabung. Perubahan yang paling baru menang, dan penghapusan tetap tercatat.
  • Kelola Bebas di File Manager: Berkas petapikir.json dapat dilihat, disalin, atau dipindahkan langsung dari aplikasi File Manager ponsel.
