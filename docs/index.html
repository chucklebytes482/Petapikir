PetaPikir

Aplikasi Mind Map Radiant Adaptif 100% Luring untuk Android dengan pencadangan JSON otomatis ke penyimpanan perangkat.

Unduh APK Rilis Terbaru
100% Luring • 0 Izin Internet • Ringan < 10 MB • Tema Otomatis Sistem

Panduan Fitur Utama

  • Tata Letak Radiant 360° Seimbang: Cabang peta pikiran memancar simetris dari pusat ke segala arah dengan penyesuaian halus untuk layar Potrait dan Landscape agar rapi, rapat, dan bebas tumpang tindih.
  • Layar Penuh & Auto Fokus: Ketuk tombol Radiant sekali untuk masuk mode Radiant Potrait; ketuk sekali lagi saat sudah di mode Radiant untuk langsung masuk Landscape Layar Penuh dengan kamera otomatis mengepas layar.
  • Mode List & Tautan Web: Beralih ke tampilan daftar terstruktur kapan saja. Node yang disorot menampilkan seluruh teks, sedangkan tautan web ditampilkan sebagai ikon di ujung kanan cabang.
  • Pencarian Cepat & Gestur Ringkas: Gunakan ikon cari di bilah atas untuk melompat ke isi atau tautan node, dan ketuk dua kali (double-tap) pada cabang untuk mengedit.

Pencadangan Lokal Otomatis (Luring Penuh)

  • Default Langsung di Documents: Setiap perubahan peta pikiran otomatis dicadangkan sebagai berkas .json langsung ke jalur default berikut tanpa membuat subfolder otomatis: 
    /storage/emulated/0/Documents/
  • Bebas Pilih Jalur di Dalam Documents: Ketuk kartu Pencadangan Lokal di bagian paling atas Beranda untuk memilih folder apa pun di dalam /storage/emulated/0/Documents/ melalui pemilih folder Android atau mengetik sub-jalur opsional (kosongkan lalu simpan untuk kembali langsung ke /storage/emulated/0/Documents/).
  • Real-Time & Kelola Lewat File Manager HP: Setiap perubahan diterapkan secara otomatis dan langsung ke berkas .json di penyimpanan perangkat sehingga berkas cadangan dapat dilihat, disalin, atau dikelola langsung melalui aplikasi File Manager ponsel.
  • Format JSON Ramah-AI: Setiap peta disimpan sebagai berkas .json terpisah dengan struktur outline, tree, dan nodes.
